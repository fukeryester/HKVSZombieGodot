# 数值配置

七份 Excel 是编辑入口。只修改“配置值”列，保留参数 ID；可排序，不可删除行、重复 ID 或输入公式。初始参考值用于对照，不会被导入。

运行 `node tools/compile-config.mjs` 导入。`node tools/build.mjs web` / `all` 会先自动导入，校验失败则阻止构建。需要 Python 3 与 openpyxl（仅用于读取）；构建产物含导入后的数据，玩家不需要 Excel 或 Python。

- 兵种：84 个兵种的数值、单兵显示体型倍率、食物/木头/黄金/石头。四资源成本优先于旧金币基数，修改某一种资源时会固定该兵种的完整四资源价格。
- 文明：采集、人口、价格、研究与农民训练等文明倍率。
- 技能：技能冷却、持续时间和公开效果属性。冷却填写最终秒数，保留当前默认 35% 缩减。
- 建筑经济：文明建筑、通用建筑、升本成本。
- 战争巨兽：巨兽生命、伤害、速度、距离等。
- 战场布局：屏幕留白、道路位置/纵深、透视、全局尺寸；以及逻辑战线长度、两边基地到边界的距离、同队基地间隔和出生偏移。显示长度和逻辑长度分列，需要同时调整；显示参数不会改变行军时间。
- 高级规则：原规则中的数值字面量，包括技能代码内的数量/效果/持续时间、经济公式、AI 阈值、巨兽机制和排位参数。ID 指向固定版本源码位置，来源列及上下文用于核对。此表也包含数组索引、循环边界、计时精度等程序常量，不能把它们当作普通平衡参数随意改动。当前尚未将这些高级参数逐一改造成语义化字段。

优先级：高级规则先参与规则初始化，再应用常用表中相对初始值发生变化的覆盖。未修改的参考值不覆盖高级规则计算。不要同时从两个入口修改同一属性。

原始 runtime/core 保留，用于核对；导入结果在 runtime/configured 与 runtime/tuning.js。不要手改生成结果。schema.json 是当前规则版本的字段注册表，规则源码变化会触发导入失败，须由开发者迁移，不能重新生成表覆盖策划修改。

每套玩法配置带哈希，新录像在配置不同的版本中拒绝播放；请保留录制版本。联机传输配置哈希以发现版本差异。

这一版恢复 v1.1 的道路投影和全局尺寸，保留多帧动画、死亡表现、紧凑 UI、技能冷却及随机显示纵深。
